# 🐋 Deep Ocean Savings: คู่มือใช้งาน (Windows)

โปรแกรมคำนวณเงินฝากแบบดอกเบี้ยทบต้น + ฝากเพิ่มต้นงวด สำหรับงานวิชา AM200 บทที่ 3 (Recurrence Relation)
ดอกเบี้ยที่ธนาคารกำหนด: **2% ต่อปี** (แก้ได้ที่บรรทัด `ANNUAL_RATE = 0.02` ใน `app.py`)

---

## 📁 ไฟล์ในโฟลเดอร์นี้

| ไฟล์ | หน้าที่ |
|---|---|
| `app.py` | **source code หลัก** ใช้ส่งอาจารย์ (มีคณิตศาสตร์ทั้งหมดอยู่ในไฟล์นี้) |
| `style.css` | ตกแต่งหน้าตาธีมมหาสมุทร (ไม่เกี่ยวกับคณิต) |
| `.streamlit/config.toml` | สีหลักของธีม |
| `requirements.txt` | รายชื่อไลบรารีที่ต้องติดตั้ง (Streamlit) |
| `install_once.bat` | ดับเบิลคลิกเพื่อติดตั้ง Streamlit (ทำครั้งเดียว) |
| `run_app.bat` | ดับเบิลคลิกเพื่อเปิดโปรแกรม |

## 🛠️ ติดตั้งครั้งแรก (ทำครั้งเดียว ประมาณ 10 นาที)

### ขั้นที่ 1: ติดตั้ง Python
1. เปิด **Microsoft Store** ค้นหา **Python Install Manager** แล้วกด **Install**
   (ถ้าใช้ Store ไม่ได้ ดาวน์โหลดจาก https://www.python.org/downloads/ และถ้าเป็นตัวติดตั้งแบบเดิม ต้องติ๊ก **Add python.exe to PATH**)
2. กดปุ่ม Windows พิมพ์ `cmd` แล้ว Enter จากนั้นพิมพ์
```
python --version
```
ครั้งแรกอาจดาวน์โหลด Python ให้อัตโนมัติ ถ้ามีคำถามให้ตอบ `y` ถ้าขึ้น `Python 3.1x.x` (3.11 ขึ้นไป) แปลว่าพร้อมแล้ว 🎉

> คู่มือฉบับละเอียด (รวมการทำลิงก์ผ่าน GitHub + Streamlit Cloud) อยู่ในไฟล์ PDF ที่แยกให้

### ขั้นที่ 2: แตกไฟล์ zip
คลิกขวาที่ไฟล์ zip → **Extract All** แล้ววางไว้ที่ไหนก็ได้ เช่น Desktop

### ขั้นที่ 3: ติดตั้ง Streamlit
ดับเบิลคลิก **`install_once.bat`** แล้วรอจนขึ้นคำว่า `Done!` จากนั้นกดปุ่มอะไรก็ได้เพื่อปิด

---

## ▶️ เปิดโปรแกรม (ทุกครั้งที่จะใช้)

1. ดับเบิลคลิก **`run_app.bat`**
2. รอสักครู่ เบราว์เซอร์จะเปิดหน้าโปรแกรมให้เอง (ที่อยู่ `http://localhost:8501`)
3. ถ้าหน้าต่างดำถามว่า `Email:` ให้กด **Enter** ข้ามไปได้เลย
4. ใช้เสร็จแล้ว ปิดหน้าต่างดำเพื่อหยุดโปรแกรม

ถ้าดับเบิลคลิกไม่ได้ ให้เปิดหน้าต่างคำสั่งในโฟลเดอร์นี้ (คลิกที่ช่องที่อยู่ของโฟลเดอร์ พิมพ์ `cmd` แล้ว Enter) จากนั้นพิมพ์
```
python -m streamlit run app.py
```

### ❓ ถ้าเจอปัญหา
| อาการ | วิธีแก้ |
|---|---|
| `'python' is not recognized` | ตอนติดตั้ง Python ลืมติ๊ก Add to PATH ให้ติดตั้งใหม่แล้วติ๊กช่องนั้น หรือลองใช้คำว่า `py` แทน `python` |
| `No module named streamlit` | ยังไม่ได้ติดตั้ง ให้ดับเบิลคลิก `install_once.bat` |
| เบราว์เซอร์ไม่เปิดเอง | เปิดเบราว์เซอร์แล้วพิมพ์ `http://localhost:8501` |
| ตัวอักษรไม่ใช่ฟอนต์ Prompt | ฟอนต์โหลดจากอินเทอร์เน็ต ถ้าไม่มีเน็ต จะใช้ฟอนต์ไทยของ Windows แทน โปรแกรมยังทำงานปกติ |

## 🧮 คณิตศาสตร์ที่โปรแกรมใช้

ตัวแปร: P = เงินต้น, r = ดอกเบี้ยต่องวด, d = เงินฝากเพิ่มต้นงวด, n = จำนวนงวด, Bₙ = เงินเมื่อสิ้นงวดที่ n

- สมการเวียนเกิด: **Bₙ = (1+r)(Bₙ₋₁ + d), B₀ = P**
- สูตรทั่วไป (สูตรหลักของโปรแกรม): **Bₙ = (P + (1+r)d/r)(1+r)ⁿ − (1+r)d/r**
- ถ้าฝากทุกปี: r = 0.02 และ n = จำนวนปี
- ถ้าฝากทุกเดือน: r = 0.02/12 และ n = 12 × จำนวนปี
- ตั้งเป้าหมาย G: ให้ Bₙ = G แล้วย้ายข้างสูตรหลัก เพื่อหา d หรือ P

ทุกครั้งที่คำนวณ โปรแกรมจะวนสมการเวียนเกิดทีละงวดเพื่อตรวจว่าได้ค่าเท่ากับสูตร และขึ้น ✅ ถ้าตรงกัน

## 🎬 แนวทางอัดคลิป (ประมาณ 5–8 นาที)

1. **แนะนำโจทย์** (30 วินาที): ฝากเงินต้น ดอกเบี้ยทบต้น 2% ต่อปี ฝากเพิ่มต้นงวด
2. **เปิด `app.py` อธิบายทีละส่วน** ตามหัวข้อในโค้ด
   - ส่วนที่ 1: ดอกเบี้ยที่ธนาคารกำหนด
   - ส่วนที่ 2: สูตรคณิตศาสตร์ (ชี้ฟังก์ชัน `balance` ว่าเป็นสูตรที่หาด้วยมือ และ `rate_and_periods` ที่แปลงหน่วยปี/เดือน)
   - ส่วนที่ 3: เครื่องมือแสดงผล (กราฟ ตาราง)
   - ส่วนที่ 4: หน้าจอ (ปุ่ม คำถาม 4 ข้อ ผลลัพธ์)
3. **สาธิตการใช้งาน**
   - ถามรอบที่ 1: ฝากทุกปี (เช่น P = 10,000, 10 ปี, ปีละ 5,000 → 68,033.52 บาท)
   - ถามรอบที่ 2: เปลี่ยนเป็นทุกเดือน (เดือนละ 500 → 78,682.42 บาท) ให้เห็นว่าถามซ้ำได้เรื่อย ๆ
   - ชี้สูตรที่แทนค่า และแถบ ✅ ที่ตรวจกับสมการเวียนเกิด
   - เปิดตารางรายงวด และลองแท็บ "ตั้งเป้าหมาย"
4. **สรุป** (30 วินาที): โปรแกรมใช้สูตรทั่วไปที่หาด้วยมือ ใส่ n ได้ทันทีโดยไม่ต้องคำนวณทีละงวด
